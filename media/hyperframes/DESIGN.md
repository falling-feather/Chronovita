# Chronovita 双旗舰课堂短片视觉规范

本文件是 `chronovita-dayu-intro` 与 `chronovita-shangyang-intro` 两个 HyperFrames 工程的共同视觉事实源。短片服务于七年级课堂导读，不模拟历史现场，不生成历史人物肖像；所有视觉均由文字、地图、河道或制度图形、时间轴和器物轮廓构成。

## Style Prompt

把课堂界面想象成一张在深蓝展柜中展开的卷宗：青铜色标尺负责年代、来源与边界，纸色承担核心问题，青绿色只指示河道、证据流与可行动信息。构图参考博物馆展签与工程图纸，保留网格、坐标、档案编号和手工纸张的温度；运动克制而有方向，像翻动卷宗、推进地图和校准尺度，不使用炫技镜头或拟真历史重演。

## Colors

- `#071A28` — 夜蓝主画布；所有场景保持同一底色。
- `#0B2431` — 深蓝面板；用于档案卡、时间轴底板和结构分区。
- `#F2E7CF` — 卷宗纸色；用于标题与最重要的结论。
- `#D1A461` — 青铜；用于年代、标尺、边界和来源身份。
- `#54C9C3` — 青绿；用于河道、证据流、当前节点和正向反馈。

正文弱化色只允许由纸色或青绿色降低透明度获得，不另造灰色体系。所有文字须通过 WCAG AA 对比检查。

## Typography

- 标题与问题：`STKaiti` / `KaiTi`，600–700；像卷宗题签，中文不做伪书法笔触。
- 正文、来源、变量与数据：`Microsoft YaHei`，300–700；数字启用等宽数字。
- 标题最小 64px，正文最小 26px，数据标签最小 18px。深色背景正文采用较轻字重与更宽行距。

## Layout

- 1920×1080，四周安全区 112px；主内容以左右分区或上题签、下图解组织。
- 每幕至少三层：深蓝网格或局部光晕、主要叙事、青铜标尺或档案标签。
- 不使用同尺寸卡片铺满画面；以一个主问题、一幅图解和一组次级证据构成视线顺序。
- 每幕设置清晰的材料身份标签：传说、传世文献、考古观察或教学解释。

## Motion

- 主转场为 0.5 秒水平卷宗推进；主题转折可用一次 0.55 秒纵向推进，收束以 0.7 秒淡入深蓝结束。
- 所有场景先完成静态英雄帧布局，再使用 `gsap.from()` 入场；非末幕不单独退场。
- 入场速度 0.28–0.8 秒，至少混用 `expo.out`、`power3.out`、`sine.out`；同一幕不从同一方向重复进入。
- 环境运动仅限河道缓慢横移、标尺扫描、地图呼吸或卷宗网格漂移；使用有限重复且保持可寻址、可复现。
- 不闪烁，不快速剪切，不使用无限循环；首个动作延后 0.2 秒。

## Caption and Accessibility

- 无旁白、无配乐；每幕必须在画面内完整表达核心信息，并与本地 Markdown 文字稿逐段对应。
- 单个阅读块不超过两行；屏上固定阅读时间至少覆盖正常朗读所需时间的 1.5 倍。
- 标明“角色化教学表达，不是史料原话”只在人物召见场景出现；本导读不引用人物台词。
- 学生可随时跳过，海报和文字稿可在断网状态使用。

## What NOT to Do

- 不伪造人物肖像、历史现场、古地图原貌或出土文物的写实复原。
- 不把传说、后世文献、考古材料和教学解释混成同一证据等级。
- 不使用霓虹渐变字、紫蓝科技渐变、玻璃拟态、同尺寸卡片墙或无意义粒子。
- 不用纯黑、纯白或与产品无关的新强调色；不使用被列为模板化默认的字体。
- 不依赖 TTS、外部视频、在线音乐、随机数或运行时网络资源。
