Chronovita · 课堂使用说明

一、第一次打开
1. 安装 Windows 64 位 Python 3.11；安装时勾选“Add python.exe to PATH”。
2. 把 ZIP 完整解压到普通文件夹，不要在压缩包里直接运行。
3. 双击“启动Chronovita课堂.cmd”，等待浏览器打开。
4. 按提示设置管理员密码。登录账号是 admin，密码是你刚设置的；没有默认密码。
   若浏览器未自动打开，访问 http://127.0.0.1:8000。

二、给学生使用
1. 管理员登录后，在“账户管理”创建账号，角色选择“学生”。
2. 退出管理员账号，再用学生账号登录。
3. 打开“课程中心”→选择课程→进入课时，先从“踏勘”阅读课文。
4. 笔记可在“卷宗/学习书案”保存；需要老师查看时，明确点击提交。
   管理员不是学生账号；教师请使用“教师”角色登录内容编辑与批阅页面。

三、同一局域网的学生访问
在解压文件夹打开 PowerShell，执行：
  .\scripts\classroom.ps1 -Lan
把启动窗口显示的学生访问地址发给同一网络内的学生。
需要时允许 Windows 防火墙在“专用网络”内访问；不要向公网开放。
默认双击启动只允许本机使用。

四、关闭与保留数据
双击“关闭Chronovita课堂.cmd”。
账号和已上传成果在 data\classroom 中；私人草稿在学生所用浏览器中。
不要清理浏览器数据或删除整个解压文件夹。升级前先停止并备份数据。

五、史记阅读与在线 AI
- “史记阅读”可选择卷章、简繁字形、逐句译读和书影；自动整理内容保留人工待校标记。
- 下载独立《史记》书影 ZIP 后，在解压文件夹执行：
  .\scripts\install-shiji-facsimile.cmd D:\下载\Chronovita-Shiji-Facsimile-v2.zip
  没安装书影仍可阅读正文和 OCR 转写；完整书影约需额外 1.7GB 空间。
- 管理员在“API 配置”录入模型地址、名称和密钥，再选择在线服务。课堂里的 AI 共用此配置。
- 教师需向课程仓库提交内容时，在同一页录入 GitHub 令牌并启用发布；仓库自动绑定，不用学生填写。
- 清除密钥会关闭对应服务，不会删除课文或笔记。

六、常见问题
- 页面打不开：查看启动窗口；端口占用时运行 .\scripts\classroom.ps1 -Port 8001。
- 忘记学生密码：请管理员在“账户管理”重置。
- 断网：已安装 Python 后，包内依赖可离线安装；阅读、笔记及已有本地功能可用，在线 AI 需要另行配置。
- 需要排障：日志在 .chronovita-classroom\logs。

本版以教师课文阅读为准；互动按各课实际开放情况进入。参考补充资料保留来源及待审状态。
ZIP 校验值见同名 .sha256；第三方许可见“依赖与模型许可清单.json”。
