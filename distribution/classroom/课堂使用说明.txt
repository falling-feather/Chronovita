Chronovita V0.10 Windows / LAN 课堂包

一、启动
1. 将 ZIP 完整解压到本机普通文件夹，不要直接在压缩包内运行。
2. 安装 64 位 Python 3.11；首次运行会在解压目录创建 .venv。
3. 双击“启动Chronovita课堂.cmd”。默认仅本机可访问，地址为 http://127.0.0.1:8000。
4. 第一次启动会安全提示创建管理员密码。密码输入不会显示，也不会写入源码或配置文件。

二、局域网课堂模式
在 PowerShell 中进入解压目录并显式运行：
  .\scripts\classroom.ps1 -Lan
启动器会绑定 0.0.0.0，并列出可供同一局域网学生访问的地址。仅在可信课堂网络中使用此模式；系统没有宣称提供公网 TLS、多租户或灾备能力。

三、停止
双击“关闭Chronovita课堂.cmd”。账号、课程进度、卷宗和知识画板数据会保留在 data\classroom 中。

四、离线边界
包内包含预构建网页、双旗舰课程短片、Python 3.11 Windows wheelhouse 与校验过的 BGE 向量模型。完成首次安装后，断网仍可登录、观看短片、执行固定行动、使用 FTS 检索与抽取式回答、生成卷宗并保存知识画板。在线生成模型不可用时不会阻断上述闭环。

五、故障提示
- 端口被占用：使用 -Port 8001 等参数改用其他端口。
- 模型损坏或缺失：启动器会明确警告并退回 FTS5，不会使用模型常识补写。
- 查看日志：.chronovita-classroom\logs。
- 重置管理员密码请登录管理员工作区执行；不要修改数据库文件。

依赖与模型许可见“依赖与模型许可清单.json”，发行文件旁的 .sha256 用于核对 ZIP 完整性。
