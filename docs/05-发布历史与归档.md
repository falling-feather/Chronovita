## 3. 版本记录

### Implement content review and release workflow (BE-001)

- 新增独立内容工作流，覆盖保存、最低校验、提交审校、退回、通过、封存、发布和回滚；实质内容变化会使旧批准失效，相同内容重复保存不会误撤销状态。
- 每门课程使用不可变 release manifest 与原子 active pointer；发布或回滚先复验全部制品与跨课程课时 ID，再写后台工作流投影，最后才把 active pointer 作为学生端提交点。短生命周期事务日志支持进程中断后的启动恢复，可重入全局工作流文件锁串行化本机多 worker 的保存、审校与发布。
- 发布时把旧教师内容包规范化为 `CoursePackageV1`，同时固定源 sealed checksum、V1 checksum 和 release checksum；学生课时响应带 release 身份，损坏发布返回稳定 `503`。
- 学生端取消旧 sealed 目录的隐式 fallback；历史内容必须由管理员显式列出 `lesson_id + content_version`，经最低校验后生成 bootstrap release。
- admin token 移除通用默认值，一键启动进程生成随机 token；审计身份取认证后的服务端 actor，不信任请求体署名；单文件写入采用同目录临时文件、`fsync`、原子替换或只创建硬链接。
- 后端全量 50 项测试通过，新增 API 全链路、封存不可见、显式迁移与不合格迁移拒绝、V1/V2 发布、同课程多课时投影、跨课程 ID 冲突、按课程回滚与历史制品复验、服务重载、并发保存与审批封存并发、严格 ID 路径校验、重复保存、路径/制品篡改、源文件缺失、孤立 manifest 隔离及首发/工作流/指针/进程中断故障注入反例。
- 本次编辑器改动已在 `houduan` 干净分支独立通过生产构建；浏览器在桌面与移动视口完成“保存—校验—审校—封存—发布—学生课程页—回滚”验收。课程页第三方视频播放器在受限网络中仍会产生其自身请求告警，不影响课程内容读取。

### Freeze runtime contracts V1 (ARCH-001)

- 新增 `CoursePackageV1`、`ScenarioTemplateV1`、`GameSessionV1`、`TurnV1`、`NpcStateV1` 与 `DossierV1` 不可变 Pydantic 契约和跨对象引用校验。
- 提交 JSON Schema 2020-12 文件及大禹治水课程、关卡、完整会话、卷宗和 bundle 技术样板；教学内容均明确标记为教师待审。
- 增加 sealed 制品与 final 卷宗的规范化 SHA-256 计算、篡改检测、源 checksum 验证、稳定 legacy ID 和旧 `LessonContentPackage` 保真适配。
- `RuntimeBundleV1` 可按行动、事件、NPC 与节点规则确定性重放会话，并核对回合上限、结局、时间线、卷宗全轨迹和关键选择原始输入；这是契约验真层，尚不是接收玩家输入的完整局势执行器。
- 后端测试增至 24 项，覆盖 schema 漂移与陈旧文件、未知字段、草稿/封存门槛、规则回放、状态范围、引用完整性、知识图谱边、checksum、旧内容兼容和篡改反例。
- 此提交只冻结运行契约，不改变现有课程读取、saga 或 sandbox 行为；发布闭环、规则引擎和持久化分别由 `BE-001`、`GAME-001`、`BE-002` 接续。

### V0.7.5 探索式课程 UI 与 DeepSeek V4 配置

- 课程详情页改为“章节路线 / 历史盘面 / 随行助教”三栏探索界面。
- 课时页移除旧 Tab 主导航，改为“踏勘遗址 / 进入抉择 / 召见人物 / 整理卷宗”行动罗盘。
- 新增 `CompanionPanel` 随行助教侧栏，课程详情和课时页均可召见助教或历史人物。
- DeepSeek 配置补齐 `deepseek-v4-flash` 与 `deepseek-v4-pro` 双模型字段；官方接口曾返回 402 余额不足，后端保留 mock 回落。

### V0.7.4 “同窗”自定义对象

- 同窗下拉新增“自定义对象”入口，支持姓名和一句话简介。
- 本地缓存 5 个常用自定义人物，切课时自动校验候选对象。
- 后端 `AskRequest` 扩展 `peer_intro`，注入 peer system prompt。
- 同名优先使用课程内置人物，自定义人物作为补充。

### V0.7.3 画板自动保存

- `LessonCreate` 对节点和边变化做 debounce 自动保存。
- 工具栏显示保存中、已保存时间和保存失败重试状态。
- 首次加载后延迟置 `loaded=true`，避免种子节点误触发保存。

### V0.7.2 学习进度持久化

- 后端新增学习进度 KV 命名空间与 `/learning/progress` 接口。
- `LessonPage` 进入或切换 layer 时自动 touch。
- 首页和我的学习读取真实进度，支持继续学习。
