## 3. 版本记录

### V0.7.5 探索式课程 UI 与 DeepSeek V4 配置

- 课程详情页改为“章节路线 / 历史盘面 / 随行助教”三栏探索界面。
- 课时页移除旧 Tab 主导航，改为“踏勘遗址 / 进入抉择 / 召见人物 / 整理卷宗”行动罗盘。
- 新增 `CompanionPanel` 随行助教侧栏，课程详情和课时页均可召见助教或历史人物。
- DeepSeek 配置补齐 `deepseek-v4-flash` 与 `deepseek-v4-pro` 双模型字段；官方接口曾返回 402 余额不足，后端保留 mock 回落。

### V0.7.4 “同窗”自定义对象

- 同窗下拉新增“自定义对象”入口，支持姓名和一句话简介。
- 本地缓存 5 个常用自定义人物，切课时自动校验候选对象。
- 后端 `AskRequest` 扩展 `peer_intro`，注入 peer system prompt。
- 同名优先使用课程内置人物，自定义人物作为补充。

### V0.7.3 画板自动保存

- `LessonCreate` 对节点和边变化做 debounce 自动保存。
- 工具栏显示保存中、已保存时间和保存失败重试状态。
- 首次加载后延迟置 `loaded=true`，避免种子节点误触发保存。

### V0.7.2 学习进度持久化

- 后端新增学习进度 KV 命名空间与 `/learning/progress` 接口。
- `LessonPage` 进入或切换 layer 时自动 touch。
- 首页和我的学习读取真实进度，支持继续学习。

### V0.7.1 文档体系刷新

- 文档同步到 v0.7.0，并新增项目规划。

### V0.7.0 “问”接入双模态智能体

- ask 路由使用准确度优先模型，与 saga 速度优先模型并存。
- 专家 prompt 强调教材共识、争议标注、严禁编造。
- 同窗 prompt 强调第一人称、时代边界、不预言后世。
- 前端 `LessonAsk` 支持专家/同窗切换和课程人物选择。
- 修复 React StrictMode 中 SSE chunk 重复写入问题。

### V0.6.0-V0.6.3 saga 收束与稳定性

- 增加收束触发器、persona 点名和防循环规则。
- 压力测试脚本默认 7 轮，校验收束、记忆压缩和人物一致性。
- 修复选项栏与剧情脱节、旧选项残留等问题。

### V0.5.0-V0.5.1 saga 全课程覆盖

- 48 个 saga 模板覆盖当前课程体系。
- 增加批量和压力验证脚本。

### V0.4.0-V0.4.1 saga 模板扩充

- 修复魏晋课程 ID 冲突。
- 补齐魏晋、先秦思想、秦统一、隋唐补遗等模板，累计至 30 个。

### V0.3.0-V0.3.3 看练问创首批落地

- 单节课四层页面成型。
- 先秦、秦汉、隋唐等课程逐步接入 saga。
- 接入知识画板和 AI 画板扩充。
- 增加 saga 批量验证脚本。

### V0.2.0-V0.2.9 课程体系和地图

- 建立课程、章节、关键词、人物、seed canvas 等数据模型。
- 建立 14 朝代 48 节课程正文。
- 课程中心改为 SVG 中国地图、时代时间轴和都城联动过滤。

### V0.1.0 平台壳层

- 五个顶层模块路由：首页、课程中心、我的学习、实践课堂、个人中心。
- Ant Design 主题、全局样式和页面模板库。
- FastAPI 路由骨架和 SQLite 持久化骨架。
- 初始 ADR：技术栈、持久化、LLM 适配层。
