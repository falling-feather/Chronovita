# 《商鞅变法：材料年代与制度代价导读》可访问文字稿

版本：`C-prequin-state / L103 / lesson-presentation v2`

时长：45 秒

形式：无声 HyperFrames 中文动画，可随时跳过

## 0–9 秒｜改革要回答什么

秦国变强，是否等于每个人都获益？

本课同时观察国家能力、制度信用，以及普通家庭承担的社会代价。结果、执行与承受者必须同时进入评价。

## 9–18 秒｜后世怎样讲述

《史记·商君列传》能保存改革记忆，不能充当现场记录。

入秦、徙木立信和变法结局的重要叙事，来自西汉成书的后世文献。文本晚于最初变法二百多年，现场细节不能逐项核验。后世文献很重要，重要不等于同时代。

## 18–27 秒｜同时代实物

公元前 344 年的商鞅方升，让标准尺度进入日常计量。

容量标准与“大良造鞅”相关铭文，为标准量器改革提供直接实物支持。一件方升不能替全部变法故事作证；实物证据更直接，也仍有自己的解释边界。画面中的器物是轮廓示意，不是写实复原。

## 27–36 秒｜较晚的出土文字

睡虎地秦简展示成熟秦制运行，不是商鞅亲笔原令合集。

简牍主要写于战国晚期与秦始皇时期，比最初变法晚一百多年。它们可以帮助观察县政、法律与基层执行怎样持续运转，仍须标清年代和用途。

## 36–45 秒｜进入六回合议事

富国强兵，由谁承担？

公开法令、耕战激励、标准尺度与县政执行会共同改变国家能力、军事准备、粮食供给、制度信用、社会压力与旧贵族阻力。让选择、代价与每条来源共同回答。数值是现代课堂模型，不是秦国统计表。
