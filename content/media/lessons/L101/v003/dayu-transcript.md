# 《大禹治水：四层证据课堂导读》可访问文字稿

版本：`C-prequin-state / L101 / lesson-presentation v2`

时长：45 秒

形式：无声 HyperFrames 中文动画，可随时跳过

## 0–9 秒｜问题从哪里开始

一场洪水，为什么会改变共同体？

先不急着判断故事“真”或“假”，把每种材料放回它自己的时代。观察材料身份，再讨论治理、权力与代价。

## 9–18 秒｜传说与传世文献

同一个“禹”，存在于不同材料层。

禹、鲧、疏河与“三过家门”的故事，保存了古人对公共责任的记忆。传说、传世文献、考古观察和教学解释具有不同材料身份；后世故事不是禹时代的现场记录，不能与考古材料直接画等号。

## 18–27 秒｜二里头的考古观察

可以观察早期国家，不能跳过历史解释。

二里头的大型都邑、道路、宫殿区、手工业作坊与礼仪器物，为理解组织能力提供材料。二里头文化与夏史高度相关，但不能自动等同；考古材料让结构可见，不会自己说出王朝名称。

## 27–36 秒｜争议与边界

局地洪水，不等于全国洪水。

积石峡约公元前 1920 年的洪水研究具有争议。它可以支持对特定地点、特定年代洪水事件的讨论，也能启发“洪水记忆怎样进入后世叙事”的追问；它不能直接证明禹本人、全国洪水或夏王朝。证据能走多远，结论才走多远。

## 36–45 秒｜进入六回合议事

水退，就等于成功吗？

六次选择会同时改变洪水风险、粮食储备、劳作者状态、聚落信任、地形知识与协作能力。让每项代价、每次变化和每条来源共同回答。数值是现代课堂模型，不是夏代统计表。
