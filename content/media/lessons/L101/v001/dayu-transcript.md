# 《大禹治水：四层证据课堂导读》文字稿

版本：`C-prequin-state / L101 / lesson-presentation v1`

时长：45 秒

形式：无声中文文字导读，可随时跳过

## 0–9 秒｜问题从哪里开始

一场洪水，为什么会改变共同体的组织方式？

本课不急着判断故事“真”或“假”，而是先把材料放回各自的时代。

## 9–18 秒｜传说与传世文献

禹、鲧、疏河与“三过家门”的故事，主要由后世文献保存。

它们能说明古人怎样记忆公共责任，却不是禹时代的现场记录。

## 18–27 秒｜考古观察

二里头的大型都邑、道路、宫殿、作坊与礼器，为观察早期国家提供材料。

“二里头文化”与“夏文化”高度相关，但不能省略中间的历史解释。

## 27–36 秒｜争议与边界

积石峡约公元前 1920 年洪水是一项有争议的自然科学研究。

局地洪水不能直接证明禹、全国洪水或夏王朝；证据能走多远，结论才走多远。

## 36–45 秒｜进入六回合议事

接下来，你将同时看见洪水风险、粮食、劳作、信任、地形认知与协作。

水退是否就等于成功？请让六次选择、每项代价和每条来源共同回答。
