## 1. 任务

- [ ] **任务 1｜GAME-003｜T0｜V1.0.4｜进行中**：让预设行动与自由陈策共用当前 `PersonaPackV1`、证据边界和人物表达，并保持六回合强制终止；验证双课固定/自由行动、断网回退和终局不被模型改写。
- [ ] **任务 2｜QA-006｜T1｜V1.0.5｜已认领**：完成双课人物问答与情景对话整链，覆盖可答、复杂、证据不足、离题、伪前提、注入、人物越界、并发和刷新恢复。
- [ ] **任务 3｜REL-003｜T1｜V1.0.5｜已认领**：全部阻断门禁通过后生成 V1 Windows 课堂候选包、SHA-256 和许可清单。

## 2. 实施顺序

1. `V1.0.4` 完成 `GAME-003`。
2. `V1.0.5` 先完成 `QA-006`，再完成 `REL-003`。

## 3. 验收门槛

- NPC 只使用当前 release、人物包、答案槽和本次召回证据。
- 简单问题本机回答；只有证据充分的复杂问题可以调用 API。
- 离题、注入、伪前提和极低命中问题不生成历史答案或伪造引用。
- 模型不能改写变量、事件、轮次、行动结果或结局。
- 断网、向量或 API 不可用时，FTS、本地回复、确定性行动和学习成果仍可用。
- L101/L103 在 accounts 模式下通过桌面双分辨率完整课堂整链。

## 4. 本阶段不做

- 不扩展其余 46 课的正式语料。
- 不用 API 或模型常识填补证据缺口。
- 不把 8—10B 模型默认放入基础课堂包；只有现行状态机 + API 无法满足验收时再独立评估。
- 不建设公网、多学校、多副本、灾备、PDF/OCR 或互联网实时检索。
