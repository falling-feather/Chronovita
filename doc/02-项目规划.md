## 1. 任务

- [ ] **任务 1｜QA-006｜T0｜V1.0.5｜进行中**：完成 L101/L103 路由基准、六回合人物对话整链和浏览器验收；覆盖本地命中、API 升级、拒答、断网回退、并发、终局与刷新恢复。
- [ ] **任务 2｜REL-003｜T1｜V1.0.6｜已认领**：全部阻断门禁通过后生成 V1 Windows 课堂候选包、SHA-256 和许可清单，并完成解压冷启动与端口回收验证。

## 2. 实施顺序

1. 完成 `QA-006`，修复全部阻断缺陷。
2. 通过门禁后执行 `REL-003`，不带缺陷打包。

## 3. 验收门槛

- 每课至少 20 条路由用例覆盖精确命中、本地拟合、含糊升级、离题、注入和不可用行动。
- 每个新 V5 回合只有一份可恢复的人物对话；旧 V5 会话缺少历史对话时保留规则旁白。
- NPC 只使用当前 release、人物包和允许证据；模型不能改写人物、变量、事件、轮次、行动或结局。
- API、模型或网络失败时仍能完成六回合、本地人物回应、卷宗和学习成果保存。
- L101/L103 在 accounts 模式下通过桌面双分辨率整链、刷新恢复和控制台检查。
- 后端、前端、构建、schema、发布身份和文档门禁全部通过后才生成候选包。

## 4. 本阶段不做

- 不扩展其余 46 课的正式语料。
- 不用 API 或模型常识填补证据缺口。
- 不把 8—10B 模型默认放入基础课堂包；只有现行状态机 + API 无法满足验收时再独立评估。
- 不建设公网、多学校、多副本、灾备、PDF/OCR 或互联网实时检索。
