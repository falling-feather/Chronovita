## 0. 当前结论

`V0.10.31` 已完成滚动画廊登录、WebGPU 材质日晷开屏、六时代主体联动与无缝长卷；当前只继续双课用户验收与 prerelease 收口。

## 1. 待办任务

- [ ] **任务 12｜T1｜ACCEPT-001｜用户内容与课堂验收**：用户以学生和教师身份完整检查 L101/L103，登记阻断问题；两课正文、抉择、问答、书案和教师反馈均确认后通过。
- [ ] **任务 13｜T1｜REL-001｜V0.10 prerelease 发布**：任务 12 通过后更新 PR #4，合入 `main`，重建 Windows 单端口课堂包、SHA-256 与许可清单，并发布最后小版本 prerelease。

## 2. 发布门槛

- 用户确认两门旗舰课的内容、表达和课堂节奏。
- 必需检查全部通过，版本、课程、证据、视频、模型、视觉资产与发行包 checksum 一致。
- 发行包从干净提交构建；出现问题时使用新 `revert` 提交和上一份不可变课程 release 回滚。

## 3. 本轮不做

- 不扩展其余 46 课的正式内容和证据库。
- 不建设公网、多学校、多副本、灾备、生产 TLS、PDF/OCR 或互联网实时检索。
- 不以额外 3D、音效或零碎装饰延迟用户验收与课堂闭环。
