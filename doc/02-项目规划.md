## 1. 任务

- [x] **任务 1｜QA-006｜T0｜V1.0.5｜已完成**：48 条双课路由、离线双六回合人物链、Release #8 边界、L103 64 题检索和 accounts 浏览器整链均通过；浏览器结果为 11 通过、13 按职责跳过。
- [ ] **任务 2｜REL-003｜T1｜V1.0.6｜已认领**：全部阻断门禁通过后生成 V1 Windows 课堂候选包、SHA-256 和许可清单，并完成解压冷启动与端口回收验证。

## 2. 实施顺序

1. 执行 `REL-003`，从 V1.0.5 干净提交生成候选包。
2. 复核 SHA-256、许可清单、解压冷启动和端口回收，不带缺陷发布。

## 3. 验收门槛

- Release #8 的课程、关卡、证据、展示和人物包 checksum 必须与候选包 manifest 一致。
- 候选包断网后仍能完成登录、固定行动、本地人物回应、词法检索、卷宗和学习成果保存。
- 解压冷启动只监听 `127.0.0.1`；显式 LAN 模式才显示学生地址，停止后端口必须回收。
- 后端、前端、构建、schema、发布身份和文档的完整数量以最终全量门禁输出为准。

## 4. 本阶段不做

- 不扩展其余 46 课的正式语料。
- 不用 API 或模型常识填补证据缺口。
- 不把 8—10B 模型默认放入基础课堂包；只有现行状态机 + API 无法满足验收时再独立评估。
- 不建设公网、多学校、多副本、灾备、PDF/OCR 或互联网实时检索。
