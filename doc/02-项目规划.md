## 1. 任务

当前无未完成任务。`QA-006` 与 `REL-003` 已移入[开发历史第 3.39—3.40 节](03-开发历史.md#339-v105)。

## 2. 实施顺序

本轮实施已结束。下一阶段必须在用户内容验收后另建任务和新版本，不在 V1.0.6 上继续堆叠范围。

## 3. 验收门槛

- 不修改 Release #8 的课程、关卡、证据、展示或人物包 checksum。
- 不让模型绕过当前发布证据、人物边界或确定性游戏规则。
- 不把本地候选包写成公开发行或公网生产部署。

## 4. 本阶段不做

- 不扩展其余 46 课的正式语料。
- 不用 API 或模型常识填补证据缺口。
- 不把 8—10B 模型默认放入基础课堂包；只有现行状态机 + API 无法满足验收时再独立评估。
- 不建设公网、多学校、多副本、灾备、PDF/OCR 或互联网实时检索。
