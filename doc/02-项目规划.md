# Chronovita — 项目规划

> **文档梗概**：只记录尚未完成的重构任务、优先级和验收结果。已经完成的版本与工作移入[03-开发历史](03-开发历史.md)，不再留在本文占篇幅。
>
> **具体规划法则**：
>
> 1. 本轮不是在现有页面上继续补丁式美化，而是重做学生端视觉语言和四阶段交互。
> 2. 任务按 `T0`（阻断后续）、`T1`（本轮必须完成）、`T2`（不影响主闭环时再做）排序。
> 3. 本规划已于 2026-08-24 获得用户确认，现按正式产品开发执行；不再把实现称为样板、占位或临时演示。
>
> **最后一次更新时间**：2026-08-24
>
> **更新者**：项目统筹组

## 0. 当前判断

- **当前基线**：`V0.10.16` 已固化长期规划、统一文档和可信双端口验收；可运行功能继承 `V0.10.14` 的账户、课程发布、两门旗舰课、关卡、RAG、卷宗、画板、视频和本地课堂包。
- **当前结论**：学生端仍是技术样板，不是可参赛、可答辩的完成品。主要问题不是局部间距或配色，而是视觉主题不统一、默认组件感过强、信息堆砌、四阶段缺少沉浸式叙事和真正的学习创作工具。
- **版本安排**：继续使用用户已授权的 V0.10 顺序补丁版本；一个提交只处理一个任务，修复继续占用下一个补丁版本，不改写历史。
- **保留边界**：后端已经形成的账户、不可变发布、课程内容、证据 checksum、学习资产归属和离线回退继续保留；前端可以重做，但不能破坏这些事实边界。

### 0.2 本次验收环境的两项错误

1. 互动关卡出现 `Cookie-authenticated writes require a trusted Origin`，原因是本次临时网页使用 `5174`，但后端仍只信任默认开发 Origin。这是验收启动配置错误，必须修正。
2. 本次临时验收服务关闭了 BGE 向量检索，实际运行的是 FTS 词法回退。因此这次页面不能代表现有混合检索的上限；但人物身份路由、自然问法覆盖、语料粒度和回答体验仍然需要重做。

以上两项是环境问题，不抵消本轮八条产品反馈。

## 1. 视觉总方向

参考 `example/古风网页` 的宣纸长卷、山河地图与器物陈列，以及 `example/huaxia-chronicle` 的暗色博物馆、发光史卷和沉浸式抉择场景，重新建立 Chronovita 自己的视觉系统，不复制参照页面。

- **天时**：首页以日晷为核心意象。Three.js 日晷的光影随本机时间变化，鼠标移动产生克制的视差和光影响应。
- **史卷**：课程路线、课文和抉择使用史书页、卷轴、批注、便签和翻页语言，不再使用大面积纯白卡片网格。
- **山河**：课程中心以可缩放历史地图和时间轴组织时代、城市、道路与事件。
- **人物**：王侯将相、学者与劳动群体作为人物剪影、印章、纹样和助教立绘出现，不伪造史料照片。
- **留痕**：第四阶段表现为学生自己的历史书案，承接笔记、手写、图画、正文、导图和前三阶段记录。
- **动效原则**：动画用于解释层级、时代切换和学习反馈；必须提供静态降级与 `prefers-reduced-motion`，不能让 3D 效果拖慢课堂设备。

## 2. 任务清单

- [ ] **任务 1｜T0｜UI-001｜V0.10.17—V0.10.18｜进行中｜全局前端重绘**：重做首页、导航、课程中心、课时壳和四阶段共同视觉；首页实现“日晷—时间—历史长卷”主场景、多层背景、鼠标视差和系统时间光影。验收时不能再出现默认 Ant Design 仪表盘感、纯色占位块或无意义技术说明。

- [ ] **任务 2｜T0｜MAP-001｜V0.10.19｜重做历史地图**：使用可核验的公共领域地图、原创绘制底图或生成式装饰素材，重做疆域、城市、路线、河流、事件和时代切换。鼠标在地图内滚动时，未到缩放边界就围绕指针缩放并阻止页面滚动；到达最大或最小级别后释放滚轮，让页面继续滚动。同步支持拖拽、按钮、触控和键盘操作。

- [ ] **任务 3｜T1｜ART-002｜V0.10.20｜补齐课程头图**：为当前 15 门课程各制作一张独立头图，建立统一构图、时代色彩和素材清单；课程卡片使用响应式 WebP/AVIF、懒加载和无图降级，不再显示纯色块。

- [ ] **任务 4｜T0｜FE-009｜V0.10.21—V0.10.22｜重做“踏勘”页面**：顶部为课程主题与头图，其下为通栏视频；再下方采用约 7:3 布局，左侧为课文，右侧为关键词和知识点。课文中的重点词支持加粗、标红、批注和点击联动，点击后以翻页或便签插入动画显示解释。学生页面删除“可复核来源”整栏，但来源数据继续保留给 RAG、教师端和卷宗引用。

- [ ] **任务 5｜T1｜AI-003｜V0.10.23｜AI 助教浮窗与临时笔记本**：把固定侧栏改成可收缩浮窗。按钮显示当前人物的透明背景立绘，展开后才出现对话、人物切换和临时笔记；切换人物时按钮形象同步变化。人物造型必须匹配具体时期和身份，例如“治水中的禹”与“建立权力秩序后的禹”使用不同形象。临时笔记按课时自动保存在本地，并在第四阶段直接出现。

- [ ] **任务 6｜T0｜GAME-002｜V0.10.24｜重做历史情景推演**：把现有关卡改成有场景、人物和连续上下文的文字冒险。每轮包含情境反馈、若干预设行动和一个自由输入框；预设行动走确定性规则，自由输入由 LLM 在当前情境内理解并映射。达到课程规定轮数后强制结束，由规则判定结果类型、LLM 生成结局叙事；只有接近经审校历史路径的选择得到正向结局，其余主要为中性或负向结果。断网时仍能用预设行动完成。

- [ ] **任务 7｜T0｜AI-004｜V0.10.25—V0.10.26｜重做“问”的 RAG + LLM 链路**：保留现有 FTS5、BGE 和 RRF 基础，增加人物身份路由、问题改写、多路召回、语义重排和基于引用的 LLM 组织回答。预设问题只作为快捷入口，不能成为可回答范围。为 48 个课时建立各自的证据切片、关键词别名、人物边界和向量索引；先用 L101/L103 做自然问法验收，再扩展全量课时。

- [ ] **任务 8｜T0｜FE-010｜V0.10.27—V0.10.28｜开发本地优先的学习书案**：第四阶段不再以导图玩具为主体，改为块式笔记编辑器，集成 Markdown 与所见即所得正文、键盘输入、手写笔迹、自由绘图、便签和导图。前三阶段的观看、关键词、选择、对话、引用和临时笔记进入本地事件账本，并可一键整理为卷宗。React Flow 只保留为“导图块”，不再代表整个创作功能。

- [ ] **任务 9｜T1｜BE-009｜V0.10.29｜打通离线保存与教师反馈**：HttpOnly Cookie 只识别账号，不保存学习正文。学习事件和草稿先写入 IndexedDB，再异步同步后端 session；网络失败不影响本地分析和编辑。教师端区分“本地草稿、已保存、已提交”状态，只查看学生明确提交的版本，并可写作业反馈和完成情况。

- [x] **任务 10｜T0｜OPS-007｜V0.10.16｜已完成｜修正验收启动方式**：固定验收脚本已把实际 Web Origin、API 代理和 accounts Cookie 写入绑定到同一端口参数；默认强制复验并启用发行 BGE，只有显式 `-LexicalOnly` 才回退，回答卡显示本次实际“混合检索 / 词法回退”。

- [ ] **任务 11｜T1｜QA-005｜V0.10.30+｜视觉资产、性能与整链验收**：建立地图、15 张课程头图、人物立绘、日晷/器物 3D 资源及其来源、许可、生成提示和压缩清单；验收 1366×768、1920×1080、键盘操作、减弱动态、刷新恢复、断网和普通课堂电脑性能，并走通两门旗舰课完整闭环。

## 3. 实施顺序

1. **先校正验收环境**：完成任务 10，保证后续判断基于可信 Origin 和真实混合检索。
2. **先定视觉再铺页面**：完成任务 1 的首页、课程中心和 L101 踏勘页原型，用户确认视觉方向后再扩展任务 2—5。
3. **再重做核心交互**：以 L101 完成任务 6—7，确认文字冒险和自然问答后迁移 L103，并扩展其余课时语料。
4. **最后打通学习成果**：完成任务 8—9，把前三阶段记录、临时笔记、卷宗、编辑器和教师反馈连成一条数据链。
5. **统一收口**：完成任务 11 后再讨论版本发布，不以“页面能打开”代替作品验收。

## 4. 整体验收标准

- 首页、课程中心、踏勘、推演、问答和学习书案具有统一但不单调的历史视觉语言。
- 两份 `example` 参照中的长卷、博物馆、地图和抉择氛围被吸收为设计原则，但页面结构和资产为 Chronovita 原创。
- 地图滚轮、关键词便签、助教浮窗、人物切换、文字冒险、自由输入和笔记编辑均可真实操作，不是展示动画。
- 两门旗舰课在线时使用 LLM 与向量检索；断网时仍可完成视频、预设抉择、词法检索、卷宗与本地创作。
- 学生端不堆砌 checksum、发布合同、检索实现等技术文案；必要证据放入可展开引用层。
- 课堂设备上首屏可用、动效平稳、文字清晰；关闭 WebGL 或启用减弱动态后仍可完成所有学习流程。

## 5. 本轮不做

- 不扩展公网、多学校、多副本、灾备和生产 TLS。
- 不为炫技把每个页面都做成 3D；Three.js 只用于日晷、少量器物或空间背景。
- 不自动上传学生私人草稿；只有明确“提交”的版本进入教师端。
- 不删除课程来源、证据 checksum 或审校记录；只从不适合学生阅读的位置移除技术展示。
- 不继续优化即将被推翻的旧卡片、旧侧栏和旧导图页面。
