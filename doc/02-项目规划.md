## 1. 任务

- [ ] 任务 1｜T0｜V1.1.0｜待用户验收：PR #11 的 L101 已同步为 Release #9；“课文同步”Skill、课程台账和来源 PR 收口均已完成。（CONTENT-004）

## 2. 实施顺序

1. 读取课程同步台账中的仓库配置与课程身份映射。
2. 校验最新 PR 的不可变归档、课程身份、提交和 checksum。
3. 导入教师端草稿并确认预览格式；不得直接改写旧封存文件。
4. 生成新的学生端课文发布；同号改题直接替换当前课文，未适配模块登记为“待同步”。
5. 检查学生端正文后，在来源 PR 留下发布身份并关闭 PR。

## 3. 验收门槛

- 教师端导入稿已逐字段确认正文、关键词、事实、人物、来源、问答和地图点与 PR #11 一致；学生端同步标题、摘要、正文、关键词、课时元数据和地图点。后端 82 项通过、1 项按环境跳过，前端 67 项通过并完成生产构建，浏览器预览无控制台错误。
- 旧 Release #8 的文件和 checksum 未修改；学生端已切换到 Release #9 `rel-28b5624648-0009`。
- 导入内容必须精确来自 PR #11 提交 `10ad1a351e75f781bf780b6347b048d861f8a8e0`，源课程为 `C-prequin-state/L101`，源内容 checksum 为 `7a857cf4698e19d76f6fbc997143cb988db91d45b1f75d6b915b8fef3e8fe829`。
- PR #11 的旧式 `course-release/v2` 不得直接降级当前发布格式；暂时沿用的练、问、创、人物或视频必须在台账中标记“待同步”。
- 不让模型绕过当前发布证据、人物边界或确定性游戏规则。
- 不把本地候选包写成公开发行或公网生产部署。

## 4. 本阶段不做

- CONTENT-004 只同步 L101 教师新稿，不顺带扩展其余 46 课。
- 不用 API 或模型常识填补证据缺口。
- 不把 8—10B 模型默认放入基础课堂包；只有现行状态机 + API 无法满足验收时再独立评估。
- 不建设公网、多学校、多副本、灾备、PDF/OCR 或互联网实时检索。
