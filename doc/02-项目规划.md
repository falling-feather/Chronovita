## 3. 验收门槛

- 高置信简单问题在本机完成；API 只处理证据充分的复杂综合题。
- 所有引用属于当前 release、当前答案槽和本次召回。
- 离题、注入、伪前提和极低命中问题不生成历史答案或伪造引用。
- NPC 口吻不提高史实确定性，模型不能改写变量、事件、轮次或结局。
- 断网、向量或 API 不可用时，FTS、本地回复、确定性行动和学习成果仍可用。

## 4. 本阶段不做

- 不扩展其余 46 课的正式语料。
- 不用 API 或模型常识填补证据缺口。
- 不把 8—10B 模型默认塞入基础课堂包。
- 不建设公网、多学校、多副本、灾备、PDF/OCR 或互联网实时检索。
