## 2. 状态口径

| 状态 | 含义 |
| --- | --- |
| `未要求` | 用户尚未要求该模块按教师 PR 重新同步 |
| `待同步` | 用户已经要求或课文变化导致该模块需要适配，但尚未通过验证 |
| `已同步` | 已与当前学生课文适配并完成验证 |
| `尚未同步` | 新课文已覆盖，该配套模块未作同步，可能与新课文不一致 |
| `不适用` | 当前课时不使用该模块，并已确认不需要建设 |

“PR 覆盖”只记录同一课时是否曾被教师内容 PR 改写过；它不表示练、问、创等模块已经同步。
