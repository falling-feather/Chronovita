## 2. 状态口径

| 状态 | 含义 |
| --- | --- |
| `未要求` | 用户尚未要求该模块按教师 PR 重新同步 |
| `待同步` | 用户已经要求或课文变化导致该模块需要适配，但尚未通过验证 |
| `已同步` | 已与当前学生课文适配并完成验证 |
| `不适用` | 当前课时不使用该模块，并已确认不需要建设 |

“PR 覆盖”只记录同一课时是否曾被教师内容 PR 改写过；它不表示练、问、创等模块已经同步。

## 4. 更新规则

1. 同步前先从当前学生 API 读取题目和 Release，不从旧文档猜测。
2. 每次只更新目标课时一行；PR、commit、源 checksum 和学生 Release 必须同时记录。
3. 学生发布成功后更新“当前学生题目”和“课文”；其他模块只在完成适配与验证后改为“已同步”。
4. 来源 PR 只有在教师预览、学生页面、测试和本文更新均通过后才能关闭。
5. 课程或课时新增、删除、改号属于目录结构变更，必须先更新当前实现，再同步本文；不得只改台账。
