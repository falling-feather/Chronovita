# Chronovita — 开发历史

> **文档梗概**：记录已经发生的独立 Git 提交和 V0.10 阶段结果；V0.9.41 及以前的完整记录继续由旧历史归档承载并从本文统一进入。
>
> **具体规划法则**：
>
> 1. Git 提交标题、日期、任务编号和提交哈希必须来自仓库事实，不把未提交工作、未来版本或验收计划写成历史。
> 2. 一次提交只对应一个版本号和一个任务编号；回滚保留原记录并新增 `revert` 提交。
> 3. 已经完成但尚未提交的工作单列为“工作区完成记录”，不得虚构 Git 版本或提交哈希；形成提交后再移入版本记录。
>
> **最后一次更新时间**：2026-08-24
>
> **更新者**：项目统筹组
