## 1. 项目定位

Chronovita 是面向中小学历史学习、学期大作业和创新训练比赛展示的历史仿真学习平台。它不是普通课程网页，也不是允许模型自由补写史实的聊天站点。

项目把课程内容、历史证据、人物知识边界、局势变量、可执行行动、状态变化、结局和学生学习成果连接为一条可发布、可回放、可审校的课堂链路。V0.10 主要服务七年级学生和本地 Windows/LAN 课堂展示。

## 2. 宏观背景与创新表达

| 创新方向 | 项目表达 | 技术落点 |
| --- | --- | --- |
| 可观察 | 区分传说、传世文献、考古判断和教学解释 | 课程包、证据片段、来源、certainty 与 chronology 边界 |
| 可干预 | 学生在历史约束中完成六回合抉择 | `ScenarioTemplateV1`、确定性规则引擎、固定与自由行动 |
| 可反馈 | 变量、人物信任、事件和代价随行动变化 | `GameSessionV1`、回合 CAS、状态轨迹和结局裁定 |
| 可复盘 | 选择、证据、解释与代价形成学习成果 | final `DossierV1`、知识画板、进度和幂等导入 |
| 可审校 | 教师内容不是页面硬编码，发布件不可变且可回滚 | 草稿—校验—审校—封存—V3 联合发布工作流 |

## 3. 课堂闭环与当前范围

V0.10 的学生流程为：

```text
统一账号登录
  → 踏勘：阅读课文、材料与本地短片
  → 抉择：完成六回合历史决策
  → 召见：向课程专家或人物提问，只引用当前发布证据
  → 卷宗：生成史官卷宗并导入知识画板
  → 保存：学习进度、会话、卷宗和画板持久化
```

本轮正式课程只有：

- `C-prequin-state / L101`：大禹治水、早期国家与权力秩序。
- `C-prequin-state / L103`：商鞅变法、富国强兵与制度代价。

其余课程继续作为既有目录和兼容内容存在，不宣称已经完成正式史实稿、证据库或同等课堂验收。

## 4. 大体技术栈

| 领域 | 技术 | 当前作用 |
| --- | --- | --- |
| 学生端与教师端 | React 18、TypeScript 5、Vite 8、Ant Design 5、React Router 7、React Flow 11、Zustand 5 | 统一登录、角色工作区、四阶段课堂、内容工作台、账户管理与知识画板 |
| API | Python 3.11—3.13、FastAPI 0.139.2、Pydantic 2.9.2、Uvicorn 0.31.0 | 同源课堂服务、权限、课程、问答、游戏、卷宗和画板接口 |
| 持久化 | SQLAlchemy 2.0、SQLite、PostgreSQL 16 验证边界 | 账号、会话、学生资产、审计、迁移和本地数据 |
| 内容与运行时 | 严格 JSON 契约、checksum、文件化不可变制品、确定性状态机 | 课程/关卡/证据/展示联合发布、回放与回滚 |
| RAG 与模型 | SQLite FTS5 中文词/二元组、FastEmbed `BAAI/bge-small-zh-v1.5`、RRF、DeepSeek 兼容适配器 | 当前发布内检索、结构化引用、人物边界与离线抽取式回退 |
| 课堂媒体 | HyperFrames、H.264 MP4、WebP poster、Markdown 文字稿 | 两门课 45 秒本地无声导读短片 |
| 质量与发行 | unittest、Vitest、Playwright、GitHub Actions、PowerShell 5.1 | 五路门禁、Windows 单端口课堂包、哈希与许可清单 |

## 5. 当前实现与未完成边界

| 能力域 | 当前事实 | 当前边界 |
| --- | --- | --- |
| 课程内容 | L101/L103 各有正式正文、史实边界、来源、30 个稳定证据片段和六回合关卡 | 最终内容仍待用户验收；其余 46 课未完成同级语料 |
| 证据问答 | 当前 V3 release/evidence checksum 内进行 FTS/BGE 检索；回答只能引用本次召回 | “您是谁”一类身份问句尚未路由到人物档案，当前可能返回“依据不足” |
| 身份权限 | `student`、`teacher`、`reviewer`、`admin` 共用 `/login` 与 HttpOnly Cookie | `legacy-local` 仅是显式本地兼容；不代表生产账户体系 |
| 学生课堂 | 踏勘—抉择—召见—卷宗、刷新恢复、画板幂等导入均已接通 | 当前表达重点是双旗舰课，不扩展复杂班级与成绩系统 |
| 本地发行 | V0.10.14 Windows ZIP、SHA-256、许可清单和独立验收解压包存在；V0.10.20 是开发线而非新发行包 | 尚未创建 V0.10 prerelease；不承诺公网、多学校、多副本或灾备 |
| 质量门禁 | PR #4 的后端、PostgreSQL、密钥历史、Windows 启动器、学生 E2E 全绿 | 用户内容验收与最终发行复核仍是发布前置 |
