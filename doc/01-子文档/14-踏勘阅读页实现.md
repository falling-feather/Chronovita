# 踏勘阅读页实现

> **任务**：`FE-009`
>
> **版本**：`V0.10.21` 起
>
> **适用范围**：学生端课时 `layer=watch`

## 1. 页面顺序

学生从上到下依次看到：

1. 课程头图与课时题名；
2. 绑定当前发布的本地导读短片与可访问文字稿；
3. 四阶段轨道；
4. 约 7:3 的史卷正文与随读知识笺；
5. 阶段切换入口。

短片已移出原有“正文 + 助教侧栏”的嵌套网格，因此占满课时内容宽度。固定助教侧栏不再出现在踏勘页；后续人物助教由独立浮窗任务接回。

## 2. 组件边界

- `LessonPage.tsx`：装配课程头图、卷首短片、阶段轨道与当前阶段。
- `LessonWatchMedia`：播放本地 MP4，按需读取发布绑定的文字稿。
- `LessonWatch`：呈现正文、关键词、地点和人物索引。
- `lessonReadingModel.ts`：纯函数完成关键词去重、长词优先和正文切分，不修改课程正文。
- `chronovita-v2.css`：提供史卷、朱砂批注、插入式便签和响应式布局。

## 3. 关键词交互

正文直接读取 `Lesson.keywords`，按“正式词条优先、长词优先”匹配原文；以“与、及、和、顿号”连接的复合词同时允许两侧有效短语回指同一正式词条。命中的词以朱砂色、粗体、下划线和编号呈现，同时保持为原句的一部分。点击正文词语或右侧索引后，知识笺才显示 `pinyin` 与 `gloss`；再次关闭不会改写课程内容或进度。

桌面知识笺固定在阅读视区一侧。小于 900px 时，选中的解释成为可关闭底部便签；未选择时不遮挡正文。键盘可聚焦所有词条，当前项同时使用 `aria-pressed` 和视觉状态标识。

## 4. 证据边界

学生踏勘页不再渲染“可复核来源”列表、发布号或 checksum。`source_refs`、release 和 presentation checksum 没有删除，继续供教师工作台、RAG、卷宗生成与服务端发布校验使用。界面精简不改变课程事实源。

## 5. 降级与验证

- 无短片时显示简短说明，正文与后续阶段不受影响。
- 文字稿只在学生请求时加载，失败时显示可重试提示。
- `prefers-reduced-motion: reduce` 下取消便签插入动画。
- 关键词切分由 Vitest 覆盖长短词、重复词和正则特殊字符。
- 浏览器验收覆盖桌面和 390×844：无横向溢出、无控制台错误、头图与视频正常加载、知识笺可展开/收起。
