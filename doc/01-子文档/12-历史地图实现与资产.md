# Chronovita 历史地图实现与资产

> **任务**：`MAP-001`
>
> **适用版本**：V0.10.19 起

## 1. 三层边界

地图不把一张生成图伪装成史实地图，而是把视觉、定位和教学解释分层：

| 层 | 当前实现 | 能表达什么 | 不能表达什么 |
| --- | --- | --- | --- |
| 地形纹理 | `chronovita-terrain-atlas-v1.webp` | 山地、河谷、平原和海岸的空间气氛 | 真实地形测绘、历史疆界或考古结论 |
| 现代定位线 | Natural Earth 1:50m Admin 0 简化路径 | 帮助学生识别现代中国的大致空间位置 | 任何朝代的疆域、政权主张或历史边界 |
| 教学叠加层 | 时代范围、水系、路线、城邑和事件数据 | 课堂中的空间关系、路径和政权切片 | 县级精度、同时期所有政权或无争议的唯一复原 |

学生端固定显示“历史范围为课堂示意 · 现代轮廓仅作定位”。生成式地形没有文字、旗帜、疆界、人物和建筑，不参与课程检索或证据引用。

## 2. 资产台账

### 2.1 地形纹理

- **文件**：`apps/web/public/assets/maps/chronovita-terrain-atlas-v1.webp`
- **规格**：1536×1024，575,152 bytes，WebP quality 84。
- **SHA-256**：`6504ac5abb86c42c9feeabdd750610388ccc0a1efd2144f8ed5ac5e002405696`
- **生成方式**：Codex 内置 image generation；原始 PNG 保留在本机生成目录，仓库只保存压缩后的产品资产。
- **最终提示**：`stylized-concept`；为历史学习网站生成无文字、无符号、无疆界、无人物、无建筑的古代山水制图地形底纹，包含山脉、平原、河流与东部海面，使用暖宣纸、深赭墨线和克制矿物蓝灰，只作准确矢量数据下方的装饰层。

### 2.2 现代定位线

- **来源**：[Natural Earth 1:50m Admin 0 Countries](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/)。
- **许可**：[Natural Earth Terms of Use](https://www.naturalearthdata.com/about/terms-of-use/) 声明其矢量与栅格数据属于 public domain。
- **仓库制品**：`apps/web/src/pages/courses/chinaReferencePath.ts`。
- **生成脚本**：`scripts/generate_natural_earth_china_path.py`；脚本选择 China、Taiwan、Hong Kong S.A.R. 与 Macao S.A.R. 几何，简化并投影到 1000×720 教学坐标系。
- **重新生成**：

```powershell
.\.venv\Scripts\python.exe scripts\generate_natural_earth_china_path.py
```

该线只以低对比虚线出现。Natural Earth 的当代边界表达不用于裁定历史范围。

## 3. 交互契约

- 默认 100% 为最小缩放；鼠标向下滚动直接继续浏览页面。
- 地图尚未到缩放边界时，滚轮围绕指针缩放并阻止页面滚动。
- 到最大或最小缩放后，同方向滚轮不再 `preventDefault`，并短暂显示边界提示。
- 拖动平移不能把视口移出地图数据边界；双指距离用于缩放。
- 键盘支持 `+`、`-`、方向键、`Home` / `0`，工具按钮带名称和禁用状态。
- 城邑支持鼠标、触控和键盘选择；同地点的不同时代名称自动错位，避免点击目标完全重叠。
- 城邑札记与课程筛选由 HTML/React 输出，生成式图片中的视觉内容不进入可访问名称。

## 4. 性能与降级

- 地形 WebP 为单个 562 KiB 左右的延迟加载资源，跟随 `EraMapView` 懒加载块请求。
- 地图主体为 SVG；关闭图片、图片请求失败或开启减弱动态后，城邑、水系、路线、时代切换和课程入口仍可使用。
- `eraMapViewport.ts` 是缩放事实源，边界释放、最大缩放、指针锚点和平移约束均有 Vitest 单测。
- 地图路径和索引数据是项目资产，不在运行时访问互联网。
