# AI 助教浮窗与临时笔记

> **任务**：AI-003
> **版本**：`V0.10.22` 起
> **适用课时**：`C-prequin-state/L101`、`C-prequin-state/L103`

## 1. 已实现结果

- 固定助教侧栏已从课堂网格删除，踏勘、抉择、召见和卷宗四阶段共用右下角浮窗。
- 收起状态显示当前人物的透明立绘与姓名；切换人物后，收起按钮和展开面板同步更新。
- 展开面板只保留人物切换、课程内问答和临时笔记，不再堆放发布号、checksum 或检索实现说明。
- L101 提供禹、鲧、益、聚落代表、治水劳作者五种身份；L103 提供商鞅、秦孝公、旧贵族代表、农耕家庭代表、军功士卒、县廷吏员六种身份，并保留不采用人物口吻的课程向导。
- 问答仍调用当前发布内 `/practice/ask/rag`，人物模式使用服务端下发的 `person_id`；紧凑回答保留正文、角色声明和引用，隐藏学生不需要的技术字段。
- 临时笔记按账号、课程和课时自动保存到浏览器本地；同一页面用自定义事件同步，其他标签页用 `storage` 事件同步。进入卷宗阶段后，笔记正文和保存时间直接显示。
- 空笔记不保留空白记录；浏览器存储失败会在浮窗内明确提示，不影响问答或课堂其他阶段。

## 2. 页面结构

```text
LessonPage
├─ 课程题头 / 四阶段内容
└─ LessonCompanion（固定于视口，不参与正文网格）
   ├─ 收起按钮：当前人物立绘 + 姓名 + 笔记状态
   └─ 展开面板
      ├─ 当前人物与身份说明
      ├─ 人物横向选择条
      ├─ 问一问：建议问题、自由输入、RAG 回答
      └─ 临时笔记：分课时文本、自动保存状态

LessonCreate
└─ 临时笔记交接笺：读取同一账号/课程/课时记录
```

浮窗在 1366×768 时限制在全局导航下方，内部内容独立滚动；390×844 时宽度为视口减 30px，不产生页面级横向滚动。收起按钮贴近视口底边，人物形象可以视觉上露出，但透明区域不拦截下方操作。

## 3. 本地数据契约

本地记录定义在 `temporaryNotebook.ts`：

```json
{
  "schema_version": "temporary-notebook/v1",
  "owner_id": "当前账号 user_id",
  "course_id": "C-prequin-state",
  "lesson_id": "L101",
  "body": "学生笔记正文",
  "created_at": "ISO-8601",
  "updated_at": "ISO-8601"
}
```

存储键由 `owner_id + course_id + lesson_id` 共同形成，正文上限 6000 字符。账号会话仍只使用 HttpOnly Cookie；本地记录不保存 access token、Cookie 内容、密码、API key 或管理员信息。V0.10.26 的学习书案会把此契约迁入 IndexedDB 事件账本，但必须继续兼容读取 v1 临时笔记。

## 4. 人物资产与生成方式

成品位于：

- `apps/web/public/assets/companions/portraits/`
- `apps/web/public/assets/companions/portraits/manifest.json`

共 11 位人物、256×320 和 512×640 两档透明 WebP，22 份成品合计 823,692 字节。`manifest.json` 记录源图 SHA-256、生成 ID、裁切格、背景色检测值、成品尺寸、字节数和 SHA-256；单元测试逐项复核。

生成模式为 imagegen 原创教学插画，每课一张严格 3×2 人物表：

- L101 生成 ID：`exec-c9025302-ed91-4e2b-b4f3-1c438859dc21`。
- L103 生成 ID：`exec-df0f9257-e25e-4e53-a293-7dc9125450ee`。

提示的共同要求是“中国水墨与克制矿物色的博物馆教育插画、全身人物、统一尺度、无文字无场景”。L101 特别要求禹处于治水劳动与协调阶段，不使用王冠、龙袍或后世帝王形象；L103 特别要求战国秦国服饰，区分改革者、政治支持者、旧贵族、农耕家庭、军功士卒和基层吏员，不使用秦汉以后帝王服饰或现代戏服。

生成器返回的是绘制棋盘格的三通道 PNG，而不是真 Alpha。`scripts/prepare_companion_portrait_assets.mjs` 因此会检测两种中性棋盘底色，计算羽化透明蒙版，逐格裁切并统一放入 4:5 透明画布；处理后在墨青与暖纸两种背景上进行人工边缘复核。原始生成 PNG 保留在 Codex 生成目录，不进入 Git；网页只发行压缩成品和可核验清单。这些图是“角色化教学形象”，不是人物真实肖像或史料复原照片。

## 5. 关键文件

| 文件 | 作用 |
| --- | --- |
| `features/classroom/LessonCompanion.tsx` | 浮窗、人物切换、RAG 问答、临时笔记与自动保存 |
| `features/classroom/companionPortraitAssets.ts` | 课时/人物名称到响应式立绘的稳定映射 |

| `scripts/prepare_companion_portrait_assets.mjs` | 抠图、裁切、压缩和 manifest 生成 |

## 6. 验证记录

- Vitest：11 个测试文件、38 项通过；包含人物映射、成品 checksum、本地记录隔离、长度限制和清除规则。
- TypeScript 与 Vite 生产构建通过。

- 当前页面没有新增应用运行错误；开发期热更新和浏览器扩展自身消息不计入产品错误。
