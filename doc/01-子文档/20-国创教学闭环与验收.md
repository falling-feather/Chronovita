# 国创教学闭环与验收

> 文档梗概：把申报书中的教学目标转成真实产品行为及可核查的验收证据。
>
> 更新时间：2026-10-11｜阶段：V1.3 / V1.4 开发基线；下表是要求对照，不是完成声明。

## 0. 教学目标

学生不只记住结论，还应能区分材料性质、说明依据、解释选择与代价，并形成自己的历史判断。教师能够看到学生主动提交的成果并给出针对性反馈。项目不把阅读点击数当作学习效果。

来源：工作区 `todo/浙江传媒学院大学生创新训练项目申报书（钮玉彬）.txt`。申报书描述预期研究，代码与验收记录描述实际完成，两者不可混写。

## 1. 申报要求与产品对照

| 申报要求 | 产品行为 | 阶段验收证据 |
| --- | --- | --- |
| 看、练、问、创四阶段 | 教师正文→有限情景→证据问答→学习书案 | 两门正式课程各完成一次全链路 |
| 参数化历史推演 | 规则结算，模型理解自由输入和组织表达 | 相同选择得到相同状态；反馈说明依据和代价 |
| 人物/专家双模式 | 身份与知识边界明确，引用当前资料 | 两种视角答同一问题；引用可返回原文 |
| 文献资料支持教学 | 课程关键词能进入史料，正文摘录保留出处 | 课程到史记→摘录到书案→再次打开出处 |
| 可编辑学习成果 | 文字、笔迹、导图和引用一起保存 | 断网保存、刷新恢复、明确提交 |
| 教师可评价 | 任务、提交版本、证据与解释反馈 | 教师批阅后学生能读反馈并再次提交 |
| 低成本 Web 教学 | 本机/LAN，同源 API，可选在线生成 | 无 API 能阅读、固定推演和保存；在线可综合回答 |
| 学习效果与可用性研究 | 采集可解释过程指标与人工评价 | 指标定义、实际样本及限制；不伪造试点结果 |

## 2. 内容与证据边界

教师课文的来源、课号和指纹由[同步台账](../04-课程同步台账.md)维护。课堂互动、史记篇章和学生引用分别保留自己的发布身份，不把不同版本悄悄拼成同一份内容。

OCR 转写、AI 初筛译读和人物教学表达必须明确标注；书影是可回核依据，不意味着转写已完成人工审定。模型可以解释当前材料，但不能生成新出处或冒充司马迁原话。

只为大禹 L101、商鞅 L105 建立本轮完整互动。其余课可以阅读、查询已提供档案、记笔记与提交成果；未适配的互动必须明确显示状态。

## 3. 评价不等于自动成绩

采用简单、教师可解释的评价维度：史实是否准确、引用能否支持判断、解释是否连贯、是否注意证据边界。教师评价与学生自行确认已读分开保存。未评价时显示“待评价”，不自动给满分或零分。

过程数据只描述实际行为，例如确认已读、保存摘录、完成一次推演、提交一个版本；不推断学生已经掌握知识。原申报中的学习提升、满意度和课堂参与效果，需要后续真实试点才能下结论。

## 4. 版本集中验收

- V1.3：运行、学习页、教师内容对齐、阅读器目录与设置、真实书影和独立安装。
- V1.4：课程史料联动、人物/专家回答、成果提交评价、两课完整体验。
- 验收共同覆盖：1366×768 与窄屏、刷新恢复、角色允许/拒绝动作、在线 API 不可用和网络中断。

阶段内不反复跑全量测试；数据、权限、幂等和引用边界采用必要的定向验证。最终报告记录通过、失败、跳过及未验证项，截图不能替代功能验证。

## 5. 暂不承诺

不建设多学校租户、生产 TLS、多副本灾备或其他二十四史；不默认部署 10B 生成模型，不为了覆盖申报术语额外引入语音克隆和复杂视频生产。已有媒体和可选模型只服务于教学目标。

完成后的可交付证据包括可运行源码、Windows 包、资料包 checksum、操作说明、集中验收记录及申报要求对照。研究报告与课堂效果结论仍需要真实教学数据。
