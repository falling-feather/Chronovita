# 问史卷与引用回答界面

> 适用版本：V0.10.25。本文记录 AI-004B 的学生问答结构、回答呈现边界、宣纸资产、响应式规则和验收结果；检索算法见[自然问答查询规划与多路检索](17-自然问答查询规划与多路检索.md)。

## 1. 目标

“召见”不再表现为技术控制台或预设问题列表，而是学生可以直接使用的一页问史卷：选择课程学者或当前课人物，用自己的话提问，阅读受证据约束的回答，并在需要时展开“据何而答”。建议问题只负责降低起步门槛，不能成为唯一可回答输入。

本次没有修改 `RagAnswerV1`、当前发布解析、人物知识边界或引用白名单。前端只重新组织学生能看见的内容，服务端技术事实仍完整保留。

## 2. 页面结构

```text
LessonPage（课程、课时、当前发布）
  └─ LessonAsk（问史卷与交互状态）
       ├─ 课程学者 / 课程人物身份笺
       ├─ 学生追问与回答历史
       │    └─ RagAnswerCard（正文、边界、引用夹页）
       └─ 快捷追问 + 自由输入
```

- `LessonAsk.tsx` 只读取服务端已解析的 `lesson.people` 和当前发布展示状态，不接受客户端自写 persona 文本。
- 课程学者使用普通教学说明；人物模式显示人物姓名、课程角色和“角色化教学表达，不是史料原话”。
- 人物选择器使用本课既有透明响应式立绘；选择后同时更新请求中的 `person_id`、身份笺和回答署名。
- 三条快捷追问只把文字放入自由输入框，学生仍可改写或完全另问。
- 回答历史保留每轮学生原问和服务端回答；新回答进入可见区域，输入框随后清空并重新获得焦点。

## 3. 回答与引用边界

`askPresentation.ts` 是学生表达适配层：

| 接口事实 | 学生主层表达 | 保留位置 |
| --- | --- | --- |
| `answer_source` | “据本课材料整理”或“本地材料摘录” | 接口、测试、教师端继续保留原枚举 |
| `uncertainty` | 可读的证据边界提示 | 原始 certainty 仍在回答契约 |
| release/checksum | 不显示 | 服务端范围校验、日志、管理端 |
| `retrieval_mode` | 不显示 | 诊断与自动化测试 |
| citations | 默认展开的“据何而答”夹页，可收起 | 引用 ID、来源、片段原样来自本次召回 |

证据不足时显示“现有材料还不能支持这个问题”，引用为空；前端不能为了版面完整伪造来源。人物身份回答仍来自当前不可变人物档案，并至少带一条人物范围内证据。错误消息会去掉 HTTP 状态和内部异常细节，改为“暂时无法翻检材料”等学生语言。

## 5. 响应式与可访问性

- 1366×768 与 1920×1080 保留课程题头、四阶段轨道和通栏问史卷。
- 390×844 隐藏重复占高的课程题头，保留可横向阅读的四阶段轨道；回答、人物和引用改为单列，输入区吸附在问史卷底部。
- 页面级 `scrollWidth` 不得超过视口；快捷追问在自身区域横向滚动且隐藏装饰性滚动条。
- 身份按钮使用 `aria-pressed`，人物列表使用 `listbox/option`，回答历史使用 `aria-live`，引用按钮通过 `aria-expanded` 和 `aria-controls` 关联材料区。
- Enter 发问，Shift+Enter 换行；加载时按钮禁用并显示“正在翻检本课材料”。

## 6. 概念到实现差异复核

| 项目 | 概念方向 | 正式实现 |
| --- | --- | --- |
| 页面层级 | 卷轴占据主要阅读面 | 保留，且与现有课程四阶段壳兼容 |
| 排版 | 大号书法标题、较疏正文 | 使用系统可用中文衬线栈，保证 Windows 离线可读性 |
| 人物 | 固定商鞅示例 | 读取 L101/L103 当前发布人物并复用响应式立绘 |
| 提问位置 | 桌面右侧批注 | 每轮追问置于回答前，移动端单列，避免长问题挤压正文 |
| 引用 | 单张装饰史料 | 支持 1—4 条真实召回片段、来源和边界说明 |
| 输入 | 单行装饰纸条 | 可多行、400 字限制、键盘提交、真实加载和错误状态 |
| 移动端 | 固定人物按钮 | 保留课程学者与人物切换，人物菜单按内容展开 |
| 动效 | 卷轴与纸页入场 | 缩短为课堂设备可承受的 CSS 动效，并提供减弱动态 |

## 7. 验收

自动化覆盖：

- `askPresentation.test.ts`：回答署名、来源翻译、边界语言和错误净化。
- `student-classroom.spec.ts`：L101/L103 在 1366×768、1920×1080 下完成登录、视频、六回合、自由提问、人物模式、引用收起/展开、卷宗、画板、刷新与学生权限拒绝。
- `ask-responsive.spec.ts`：390×844 下验证四阶段轨道、问史卷、自由输入、真实回答、引用交互、无横向溢出、无外网请求和无控制台错误。
- `scripts/run-local-student-e2e.ps1`：使用临时 SQLite、随机进程内口令、accounts Cookie、同源生产构建、词法检索和 mock 模型运行完整本地门禁，结束后验证并清理隔离目录。

V0.10.25 验收结果为前端 13 个测试文件、45 项单元测试通过；Playwright 6 项实际旅程通过、6 项按分辨率职责跳过；后端全量 445 项通过、3 项因 Windows 当前权限不支持目录符号链接等环境条件跳过。FTS 与真实本地 BGE 的 40 题自然问法基准均为 40/40，`npm audit --audit-level=moderate` 为 0 项漏洞。
