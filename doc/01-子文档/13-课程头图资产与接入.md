## 1. 设计与史实边界

15 张头图均由内置 imagegen 生成，未使用外部照片或影视画面。画面承担课程气氛、时代差异和主题提示，不作为史料、复原图或人物肖像；网页中的课程标题、朝代、板块与说明仍由 HTML 输出，生成图不承担文字信息。

统一视觉约束如下：

- 16:9 横向博物馆展陈主视觉，矿物色、纸绢肌理、克制的电影光影与水墨空间。
- 左上保留题头排版空间；画面不生成可读文字、徽标、水印或界面。
- 主要使用地景、道路、器物与远景群体，不制造名人近景肖像或“历史现场照片”。
- 不把宫殿、战争和帝王当作唯一历史主体；课程图同时呈现劳动、交通、制度、思想与社会代价。
- `C-prequin-state` 为系列视觉母图；其余图片只参考母图的色彩、肌理和展陈语言，不复用构图或主体。

## 3. 生成提示结构

母图使用的完整提示结构是：课程主题说明 + 16:9 展陈构图 + 左上留白 + 对应地景/器物/远景群体 + 矿物色与纸绢肌理 + “不生成文字、徽标、名人近景、现代物件、奇幻盔甲、伪历史照片”。

其余 14 张在同一约束前增加各自表中“主视觉内容”，并明确“只参考母图的展陈语言，创建全新主体与构图”。重新生成时必须保留此结构；若新增课程，先为课程写出能对应课文主题的地景、器物、普通人活动和代价线索，再开始生成，不能只替换朝代色。

## 4. Web 发行与降级

`scripts/prepare_course_cover_assets.mjs` 把 15 张原图中心裁切为两档：

| 用途 | 宽度 | 格式 | 加载策略 |
| --- | ---: | --- | --- |
| 课程卡片 | 720 | AVIF + WebP | `loading="lazy"`，进入视口后加载 |
| 课程路线题头 | 1440 | AVIF + WebP | 当前课程 `eager` + `fetchpriority="high"` |

浏览器通过 `<picture>` 优先选 AVIF，WebP 作为兼容回退；当前 60 个发行文件合计 `7,088,900` 字节。`courseCoverAssets.ts` 绑定稳定课程 ID、文件路径与裁切焦点，未知课程退回 `cover_color`，不会出现破图。图像均为装饰性 `alt=""`，相邻 HTML 已提供课程标题与主题，不重复朗读。

转换脚本需要 `sharp 0.35+`。若 `sharp` 不在默认 Node 解析路径，通过专用环境变量 `CHRONOVITA_NODE_MODULES` 指向包含 `sharp` 的 `node_modules`；脚本不写入原图目录，只覆盖项目内可重建的响应式发行文件和 manifest。

## 5. 自动与人工验收

- `courseCoverAssets.test.ts` 校验 15 个稳定 ID、四个变体、实际文件字节数和 SHA-256。
- 1366px 浏览器确认三列卡片均显示独立头图、无横向溢出，15 张图片在滚动后按需加载。
- 390px 浏览器确认单列卡片宽度 300px、相邻卡片顺序堆叠、首屏只加载可见图片。
- 课程路线页使用 1440 AVIF，桌面与移动端均由深色渐变保证标题可读；图片失效时仍显示课程色与完整 HTML 内容。

## 6. 视觉资产与性能验收

> **任务**：`QA-005`、`UI-003`
>
> **适用版本**：V0.10.31 起

### 6.1 发布总账

`assets/visual-release-v1.json` 是学生端视觉资产的统一发布总账。它不替代各资产族自己的详细 manifest，而是精确绑定 manifest、独立资产、程序化图形、许可说明和体积预算。

| 资产族 | 产品输出 | 实际字节 | 来源与边界 |
| --- | ---: | ---: | --- |
| 15 门课程响应式头图 | 60 | 7,088,900 | Chronovita 原创生成式教学插画，不复制第三方图片 |
| L101/L103 人物透明立绘 | 22 | 823,692 | 11 位人物各 256/512 两档；角色化教学表达，不冒充历史肖像 |
| 双旗舰推演环境图 | 4 | 482,928 | 两课各 960/1600 两档；只营造情景，不宣称现场复原 |
| 问史卷宣纸纹理 | 1 | 65,950 | 无文字、标志或外部素材的原创中性纹理 |
| 登录画廊与首页长卷 | 10 | 1,362,564 | 五张原创生成式母图的响应式 WebP；教学插画，不作为史料或精确复原 |
| 首页六时代透明主体 | 12 | 2,543,938 | 六个时代各 640/1280 两档；逐项验证真实 alpha min/max，均为原创教学视觉 |
| 首页日晷 PBR 材质 | 3 | 1,371,566 | 同一原创盘面生成 albedo、bump、roughness；静态回退与 3D 共用材质语义 |
| 山河图地形纹理 | 1 | 575,152 | 原创装饰层，无疆界、文字、建筑或测绘结论 |
| 现代定位轮廓 | 1 份代码制品 | 9,680 | 由 Natural Earth 1:50m 公共领域数据经仓库脚本生成，只作现代定位 |

各资产族 manifest 保存生成 ID 或生成政策、提示摘要、尺寸、压缩方式、成品 SHA-256 和字节数。开屏日晷不是外部 3D 模型：`ChronoscopeScene.tsx` 以本地 PBR 贴图、程序化几何和光照构成，运行时固定为 `three@0.185.1`（MIT），优先 WebGPU、回退 WebGL2 与同材质静态图，并绑定源文件 checksum。

### 6.2 自动校验

`scripts/check_web_release.mjs` 在生产构建后执行以下检查：

1. 总账版本必须与前端 package 版本一致。
2. 七份子 manifest、114 个视觉输出/独立制品、现代定位路径和日晷源文件逐项复核字节数与 SHA-256。
3. 六时代响应式素材必须同时包含全透明与不透明像素；所有输出路径不得越出自身目录；公开视觉目录不得超过 15,000,000 bytes。
4. `dist/` 不得超过 18,000,000 bytes；初始 HTML 直接加载与 preload 的原始字节不得超过 1,000,000 bytes。
5. 普通 JS 分块不得超过 260,000 bytes，CSS 分块不得超过 200,000 bytes；Three.js WebGPU 分块必须唯一、独立、非首屏 preload，并小于 800,000 bytes。

当前 V0.10.31 实测：

| 指标 | 结果 | 预算 |
| --- | ---: | ---: |
| 公开视觉资源 | 14,365,034 bytes | 15,000,000 bytes |
| 完整 Web 构建 | 17,210,839 bytes | 18,000,000 bytes |
| 初始入口原始字节 | 930,394 bytes | 1,000,000 bytes |
| 最大普通 JS 分块 | 227,737 bytes | 260,000 bytes |
| Three.js WebGPU 独立分块 | 770,341 bytes | 800,000 bytes |
| 最大 CSS 分块 | 189,564 bytes | 200,000 bytes |

学生、教师和管理页面在 `App.tsx` 中按路由懒加载；课时书案、成果查看器、山河图与 Three.js 继续二次拆分。Three.js 的构建体积警告是被预算约束的独立可选块，不会阻塞登录、标题或课堂主行动。

### 6.3 浏览器验收

`classroom-quality.spec.ts` 把视觉降级与键盘能力并入既有 accounts 单端口整链：

- 1366×768 与 1920×1080 均验证减弱动态时跳过开屏、停止长卷动画，且不请求 Three.js 分块。
- 两种桌面分辨率均验证登录画廊、登录纸笺和首页无纵向滚动；标题、主行动和时代长卷保持可见。
- 地图可聚焦并用 `+`、方向键、`Home` 操作；城邑可用 Enter 打开札记。
- 同时禁用 WebGPU 与 WebGL2 时，日晷自动显示同材质静态图，旗舰课与课程中心按钮仍可操作。
- 390×844 继续验证问史卷与学习书案无页面级横向溢出。
- 两门旗舰课继续完整走通登录、视频、六回合、RAG、卷宗、书案提交与版本回看；教师反馈和四角色拒绝/落点继续受测。

V0.10.31 入口页面已由 IAB 实测 `webgpu` 运行态、开屏三阶段、悬停联动和无控制台错误；本地隔离 Edge 整链为 11 项通过、13 项按视口职责跳过、0 项失败，覆盖 1366×768、1920×1080 和 390×844。测试环境禁用向量模型并使用本地模型适配器，继续证明 FTS、抽取式回答和确定性课堂路径不依赖互联网。

### 6.4 执行命令

```powershell
Push-Location apps/web
npm run test
npm run build
npm run check:release-ui
npm audit --audit-level=moderate
Pop-Location

.\scripts\run-local-student-e2e.ps1
```

资产变化时必须先更新所属子 manifest，再更新总账绑定和预算；不得只提高预算来隐藏体积回退。构建与 E2E 生成的 `dist/`、`test-results/`、`playwright-report/` 和 `.chronovita-local-e2e/` 均为可重建缓存，不进入 Git。
