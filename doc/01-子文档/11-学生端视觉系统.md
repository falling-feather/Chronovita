> **任务**：`UI-001`、`UI-002`、`UI-003`
>
> **适用版本**：V0.10.31 起
>
> **视觉母版**：`doc/image/v0.10.31-首页时代联动概念.png`、`doc/image/v0.10.31-首页入场关键帧.png` 及既有课程地图、四阶段概念图。

## 1. 设计命题

Chronovita 不是通用教学后台。学生端以现代历史时间控制台为视觉母题：无衬线信息、深色玻璃、细密时间轨道与真实材质历史主体共同承载“天时、史卷、山河、人物、留痕”。历史感来自内容和材质，不来自仿古字体或纸张堆砌。

- **天时**：开屏 PBR 材质日晷完成“指针归十二—时间带展开—进入历史”的短过渡；稳定态由时代长卷驱动主体切换。
- **史卷**：课程路线、正文、批注和抉择采用题签、页边批、装订线与长卷层级。
- **山河**：地图负责空间关系，时间轴负责时代关系；两者不能退化为装饰背景。
- **人物**：人物形象是明确标注的教学插画，不冒充历史肖像、照片或考古复原结论。
- **留痕**：选择、提问、引用与笔记都应在“卷宗”阶段重新出现。

## 2. 颜色与材质

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--cv-ink-950` | `#06131c` | 首页、视频和沉浸场景底色 |
| `--cv-ink-900` | `#091c27` | 顶栏、深色分区 |
| `--cv-ink-800` | `#102d37` | 次级暗面与边框 |
| `--cv-paper-100` | `#f2e7cf` | 标题、浅卷纸高光 |
| `--cv-paper-200` | `#e6d3ad` | 正文纸面 |
| `--cv-paper-500` | `#b79b70` | 纸面弱文字、装订线 |
| `--cv-bronze-400` | `#c6a261` | 主行动、历史仪高光 |
| `--cv-bronze-600` | `#8f693a` | 青铜阴影与描边 |
| `--cv-patina-400` | `#65aaa0` | 当前节点、证据与正向反馈 |

首页材质采用石墨玻璃、青铜氧化斑、低亮时间网格和克制光晕；课程正文仍可使用纸纤维。禁止高饱和霓虹、仿古字体滥用和大面积纯色卡片墙。

## 3. 字体与排版

- 首页、导航和控件：`Inter / Noto Sans SC / Microsoft YaHei UI`，使用现代无衬线层级。
- 课程正文可使用 `Noto Serif SC / Songti SC / SimSun` 提升长文阅读感，但按钮、标题导航和状态信息保持无衬线。
- 数字与发布身份：`IBM Plex Mono / Consolas`，仅用于少量时间、轮次和校验值。
- 正文行宽控制在约 34—42 个汉字；桌面正文行高 1.9—2.05。
- 一级标题使用清晰短句；不在标题上方重复放置英文眉题或分类胶囊。

## 4. 栅格与组件

- 页面内容最大宽度 `1680px`；桌面顶栏高度 `72px`。
- 首页拒绝页面级纵向滚动，在桌面视口内完整呈现标题、时代主体、主行动和无缝长卷。
- 圆角只用于可按压控件，面板、卷页和地图以直角或 2px 微圆角为主。
- 每个视区只保留一个视觉主角；弱信息使用边注或可展开抽屉，不再堆成同权卡片。
- Ant Design 只承担表单、反馈和无障碍基础，外观由 Chronovita 语义类统一覆盖。

## 5. 动效与 3D

- Three.js 只用于开屏日晷及后续经确认的少量器物，通过 `three/webgpu` 动态导入拆包。
- 日晷使用 albedo、bump、roughness 对齐贴图和 PBR 光照；优先 WebGPU，自动回退 WebGL2，再回退同材质静态图。
- 开屏总时长约 2.55 秒，指针归十二后时间带展开并落到页面底部；Escape 可跳过。
- 稳定态鼠标视差直接写 CSS 变量；时代自动切换为 7 秒，不触发高频 React 重渲染。
- `prefers-reduced-motion: reduce` 直接跳过开屏并停止长卷自动移动，所有课程入口仍可操作。

## 6. 图像与历史边界

- 课程头图、人物立绘和器物图必须记录来源或生成说明，并在代码外保留资产台账。
- 插画不得出现“真实影像”“历史现场还原”等误导表述。
- 长城等跨时代意象只能作为首页“中华历史长卷”的象征层，不能进入不相符课时作为证据。
- UI 文本一律由 HTML 输出；概念图中的文字不作为产品正文或按钮使用。

## 7. 无障碍与性能验收

- 1366×768 与 1920×1080 下，首屏主要行动不被遮挡，正文不横向溢出。
- 所有图标按钮有可读名称；键盘可访问导航、搜索和主要行动。
- 正文与背景达到 WCAG AA；重要状态不只依赖颜色。
- WebGL 关闭、减弱动态开启和低性能设备上，所有学习功能仍可使用。
- 首屏不等待 Three.js 才显示标题和行动；3D 独立懒加载，失败不阻断页面。

## 8. 当前母版到实现的取舍

1. 保留首页“深色时间控制台 + 单一时代主体 + 底部无缝长卷”的层级。
2. 保留课程中心“地图为主、课程为次”的空间叙事。
3. 保留踏勘页“通栏视频 + 7:3 正文与知识便签”的阅读结构。
4. 保留推演、召见、卷宗各自不同的主操作，不复用同一种卡片布局。
5. 日晷是原创教学界面装置，材质真实但不宣称出土器物或精确复原。
6. 所有人物和场景资产按教学插画处理，不把生成图当作史料。

课程中心的地形纹理、现代定位线、历史范围示意和滚轮边界详见[历史地图实现与资产](12-历史地图实现与资产.md)。15 门课程的头图生成记录、响应式格式、checksum 与接入规则见[课程头图资产与接入](13-课程头图资产与接入.md)。踏勘页的通栏短片、史卷正文与交互知识笺见[踏勘阅读页实现](14-踏勘阅读页实现.md)。

## 9. V0.10.30 入口页面

- 登录页以三列、四幕原创历史教学插画构成循环长卷；表单只保留账号、密码、进入课堂和必要错误反馈。画廊可暂停，悬停与减弱动态状态下停止滚动。
- 首页为固定单屏：左侧表达课堂命题，右侧显示程序化青铜历史仪，底部时代长卷既是装饰也是课程筛选入口。
- 首页背景长卷与登录插画共有 10 份响应式 WebP，清单位于 `apps/web/public/assets/entry/manifest.json`；母图不进入 Git，生成 ID、提示摘要、源哈希和成品哈希保存在清单中。
- `ChronoscopeScene.tsx` 不依赖外部 3D 模型；几何、表盘纹理和轻量环境光纹理由代码生成。减弱动态、WebGL 不可用或动态导入失败时显示同构 SVG。
- 概念图与实现在五个关键点保持一致：深色历史画廊、右侧纸面登录笺、单屏层级、右侧青铜主器物、底部时代长卷。实现主动删去概念中的伪篆章和难以验证的器物铭文，改用可读 HTML 与“原创教学装置”边界说明。

## 10. V0.10.31 时代联动首页

- 首页改为现代无衬线单屏；半透明顶栏覆盖主舞台，不再保留稳定态的大型程序化历史仪。
- 六组透明时代主体各有 640/1280 两档 WebP；生成 ID、源哈希、透明提取过程、可见边界和成品哈希见 `apps/web/public/assets/home-era/manifest.json`。
- 底部长卷由两组同构序列首尾拼接，默认缓慢移动；鼠标进入或键盘聚焦时暂停，时代主体、标题和说明同步切换。
- 开屏日晷贴图见 `apps/web/public/assets/home-chronodial/manifest.json`，PBR 与静态回退使用同一 albedo，避免渲染器加载前后视觉跳变。
- 实机截图为 `doc/image/v0.10.31-首页实机验收.png`；所有人物、器物和场景仍标注为原创教学视觉，不作为史料或精确复原。
