# Chronovita 学生端视觉系统

> **任务**：`UI-001`
>
> **适用版本**：V0.10.17 起
>
> **视觉母版**：`doc/image/concepts/` 中的首页、课程地图和四阶段六张概念图。

## 1. 设计命题

Chronovita 不是通用教学后台。学生端应当像一座可操作的历史陈列室：以“天时、史卷、山河、人物、留痕”组织信息，让界面本身解释学习过程。

- **天时**：首页日晷表现“从当下进入历史”。光向取自学生设备的本地时间，鼠标只产生轻微视差。
- **史卷**：课程路线、正文、批注和抉择采用题签、页边批、装订线与长卷层级。
- **山河**：地图负责空间关系，时间轴负责时代关系；两者不能退化为装饰背景。
- **人物**：人物形象是明确标注的教学插画，不冒充历史肖像、照片或考古复原结论。
- **留痕**：选择、提问、引用与笔记都应在“卷宗”阶段重新出现。

## 2. 颜色与材质

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--cv-ink-950` | `#06131c` | 首页、视频和沉浸场景底色 |
| `--cv-ink-900` | `#091c27` | 顶栏、深色分区 |
| `--cv-ink-800` | `#102d37` | 次级暗面与边框 |
| `--cv-paper-100` | `#f2e7cf` | 标题、浅卷纸高光 |
| `--cv-paper-200` | `#e6d3ad` | 正文纸面 |
| `--cv-paper-500` | `#b79b70` | 纸面弱文字、装订线 |
| `--cv-bronze-400` | `#c6a261` | 主行动、日晷高光 |
| `--cv-bronze-600` | `#8f693a` | 青铜阴影与描边 |
| `--cv-patina-400` | `#65aaa0` | 当前节点、证据与正向反馈 |
| `--cv-cinnabar-500` | `#a64235` | 批注、风险和史书重点 |

材质通过细网格、纸纤维、青铜氧化斑和局部光晕表达，不使用玻璃拟态、霓虹渐变或大面积纯色卡片墙。

## 3. 字体与排版

- 导航和控件：`Noto Sans SC / Microsoft YaHei`，保证课堂设备可读性。
- 课程题名和正文：`Noto Serif SC / Songti SC / SimSun`，保留史书感但不模拟难辨认的书法。
- 数字与发布身份：`IBM Plex Mono / Consolas`，仅用于少量时间、轮次和校验值。
- 正文行宽控制在约 34—42 个汉字；桌面正文行高 1.9—2.05。
- 一级标题使用清晰短句；不在标题上方重复放置英文眉题或分类胶囊。

## 4. 栅格与组件

- 页面内容最大宽度 `1680px`；桌面顶栏高度 `72px`。
- 首页首屏在常见桌面高度内完整呈现标题、日晷、主行动和历史长卷。
- 圆角只用于可按压控件，面板、卷页和地图以直角或 2px 微圆角为主。
- 每个视区只保留一个视觉主角；弱信息使用边注或可展开抽屉，不再堆成同权卡片。
- Ant Design 只承担表单、反馈和无障碍基础，外观由 Chronovita 语义类统一覆盖。

## 5. 动效与 3D

- Three.js 只在首页日晷及后续经确认的少量器物中使用，并通过动态导入拆包。
- 日晷动画只改变相机视差、缓慢呼吸和光向；不连续自转，不抢夺阅读焦点。
- 指针高频更新写入 ref，在渲染循环中消费，不触发 React 重渲染。
- 页面进入、便签插入和卷页切换使用 180—520ms 的位移与透明度组合。
- `prefers-reduced-motion: reduce`、WebGL 不可用或画布离屏时，自动切换或暂停为等价静态图。

## 6. 图像与历史边界

- 课程头图、人物立绘和器物图必须记录来源或生成说明，并在代码外保留资产台账。
- 插画不得出现“真实影像”“历史现场还原”等误导表述。
- 长城等跨时代意象只能作为首页“中华历史长卷”的象征层，不能进入不相符课时作为证据。
- UI 文本一律由 HTML 输出；概念图中的文字不作为产品正文或按钮使用。

## 7. 无障碍与性能验收

- 1366×768 与 1920×1080 下，首屏主要行动不被遮挡，正文不横向溢出。
- 所有图标按钮有可读名称；键盘可访问导航、搜索和主要行动。
- 正文与背景达到 WCAG AA；重要状态不只依赖颜色。
- WebGL 关闭、减弱动态开启和低性能设备上，所有学习功能仍可使用。
- 首屏不等待 Three.js 才显示标题和行动；3D 独立懒加载，失败不阻断页面。

## 8. 当前母版到实现的取舍

1. 保留首页“深色博物馆 + 青铜日晷 + 底部长卷”的层级。
2. 保留课程中心“地图为主、课程为次”的空间叙事。
3. 保留踏勘页“通栏视频 + 7:3 正文与知识便签”的阅读结构。
4. 保留推演、召见、卷宗各自不同的主操作，不复用同一种卡片布局。
5. 日晷基座改为原创、克制的石台与青铜盘，不照搬概念图中的动物或龙形底座。
6. 所有人物和场景资产按教学插画处理，不把生成图当作史料。
