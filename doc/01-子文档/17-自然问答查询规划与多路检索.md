# 自然问答查询规划与多路检索

> 适用版本：V0.10.24。本文记录 AI-004A 的查询规划、检索融合、安全边界和评测方法；学生问答页面与后续语料扩展见[项目规划](../02-项目规划.md)。

## 1. 解决的问题

旧检索对证据库原词问题表现稳定，但自然口语中的“到底、靠谱吗、这事、啥”等词会进入查询覆盖率分母，导致正确片段已经进入 Top 5 仍被判为“依据不足”。人物模式的“您是谁？”没有可检索主题，也只能失败。原 40 题基准又基本复述了片段标题，不能代表学生真实提问。

V0.10.24 在不放宽证据边界、不修改 `RagAnswerV1` 的前提下增加查询规划层：学生原问被保留，同时可生成经过审计的意图、人物指代和课程规范词查询；各路独立检索，只有通过既有支持阈值的查询路能影响最终排序。

## 2. 查询规划

`services/rag/query.py` 的版本是 `chronovita-rag-query/v1`，最多生成四路查询：

1. 学生原问，永远保留。
2. 人物指代消解，如“我的亲笔法令”改写为“商鞅的亲笔法令”。
3. 课程搜索别名对应的规范词，如“搬木头”扩展为“徙木立信、制度信用”。
4. 身份、概览或证据边界意图所需的发布上下文。

当前意图包括：`identity`、`overview`、`evidence_boundary`、`causality`、`comparison` 和 `detail`。意图只影响检索与回答结构，不是历史事实。

L101/L103 别名表只把学生口语指向当前发布中已经存在的课程关键词、人物名或证据关键词。例如：

| 学生问法 | 检索规范词 |
| --- | --- |
| 挖到大禹名字了吗 | 禹、铭文、考古边界、人物证据 |
| 治水是禹一个人干的吗 | 协作、劳动、公共动员 |
| 搬木头为什么能立信 | 徙木立信、制度信用 |
| 竹简是商鞅亲笔吗 | 睡虎地秦简、年代边界、秦律 |
| 秦国变强全靠商鞅吗 | 富国强兵、多因解释 |

别名不是可引用史料，也不能进入回答正文；它只帮助找到封存在当前 release/evidence checksum 下的片段。其他课时没有正式证据库时不会借用双旗舰别名。

## 3. 人物身份问句

人物模式下，“您是谁？”等明确身份问句走专门路由：

- 姓名、角色、摘要和知识边界来自当前不可变 `CoursePackageV1.people`。
- 检索查询使用同一人物档案，但仍按 `person_id` 过滤证据。
- 回答必须至少引用一条该人物绑定的当前发布片段。
- 页面继续显示“角色化教学表达，不是史料原话”。
- 若人物不存在、没有人物范围证据或发布损坏，仍然失败关闭。

因此身份介绍不再依赖碰巧命中“谁”字，也没有绕过 RAG 引用约束。

## 4. 多路检索与排序

`HybridEvidenceRetriever.retrieve_many` 对每路查询分别执行原有检索：

```text
查询路
  → FTS5 中文词/二元组排名
  → 可用时执行 BGE 向量排名
  → 路内 RRF
多路结果
  → 只保留通过支持阈值的查询路参与最终排序
  → 第二次 RRF
  → 当前 course / lesson / release / evidence checksum 内 Top N
```

原问优先权仅在它通过支持阈值时生效。若原问包含大量口语噪声而规范词改写通过阈值，原问的低支持排名不会把正确片段挤出 Top 5。所有查询路共享同一 release scope 和人物过滤；任何跨 scope 结果都抛出完整性错误。

支持阈值保持不变：词法信号覆盖至少 40% 且前五有实际命中，或 BGE 前五相似度至少 0.82。多路检索没有通过“降低门槛”提高命中率。

## 5. 安全与失败行为

- 包含覆盖系统规则、泄露提示、伪造引用等指令的问句标记为 `instruction_override`，不执行改写。
- 包含手机、微信、互联网、电脑等明确时代错置的问句标记为 `clear_anachronism`，不因人物名或课程名命中而获得回答。
- 阻断或证据不足时返回 `insufficient_evidence`，引用为空，也不调用在线模型。
- 在线模型只接收本次最终召回片段、人物边界和代码判定的意图；输出仍需通过结构化 schema 和 citation ID 白名单。
- 模型超时、输出越界或引用逃逸时退回本地抽取式回答。
- 抽取式回答先列材料支持的判断，再列年代/材料边界；不会把多个片段简单冒充一段史料原话。

## 6. 双基准评测

仓库保留两套独立基准：

- `tests/fixtures/rag_benchmark_v1.json`：40 题规范问法，每课 20 题，守住既有精确检索回归。
- `tests/fixtures/rag_natural_benchmark_v1.json`：40 题自然口语，每课 20 题，包含身份、代词、俗称、证据边界、概览、因果和制度代价。

V0.10.24 的实际结果：

| 运行模式 | 自然问法来源进入 Top 5 | 可支持回答 | 向量实际参与 |
| --- | ---: | ---: | ---: |
| 纯 FTS5 | 40/40 | 40/40 | 0/40 |
| FTS5 + 本地 BGE | 40/40 | 40/40 | 40/40 |

重跑命令：

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_rag_retrieval.py
.\.venv\Scripts\python.exe scripts/evaluate_rag_retrieval.py `
  --vector-model-root distribution/models/BAAI-bge-small-zh-v1.5
```

脚本默认要求 Top 5 命中率和支持率均不低于 90%，输出缺失问题、实际片段和检索改写，失败时返回非零退出码。

## 8. 当前边界

- 正式自然问法别名和评测只覆盖 L101/L103；其他课时必须先形成可审校证据库，不能只复制一组通用关键词。
- V0.10.24 没有重绘 `LessonAsk.tsx`，页面仍由 V0.10.25 负责去除技术文案并改为对话史卷。
- 查询规划是确定性本地能力；在线 LLM 负责基于已召回片段组织语言，不负责决定什么可以成为证据。
